# 571 multistep seeds

`drug_list_2_multistep_seeds.csv` is the fixed 571-seed input manifest used
for the paper's main three-step prediction protocol. It is separate from the
442-root/855-target strict-gold evaluation data.

Columns:

- `seed_id`: stable seed identifier;
- `seed_smiles`: input substrate SMILES;
- `seed_canonical_smiles`: canonicalized substrate SMILES used for auditing.
